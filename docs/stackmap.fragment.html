Batch jobs, on either platform

Wrap each scheduled command

corewatch_job.sh nightly_close --max-age 93600 -- /opt/app/close.sh

The wrapper is plain POSIX sh. It records start, end, duration, exit code and last success, and passes the job's exit code through.

Three alerts read it

  • page JobFailed: the last run ended with a non-zero exit code.
  • page JobOverdue: no success within --max-age. This catches the job that never started.
  • ticket JobRunningLong: running for more than twice its 7-day average.
